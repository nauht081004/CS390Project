## Windows steps
1. Extract CS390Project-main.zip using right-click > Extract All.
2. Extract Kiran_Part3_Testing.zip separately.
3. Copy all seven files from its contribution folder into CS390Project-main/draftpart3, alongside parser.py, lexer.py, and ast_nodes.py. Do not replace those team source files.
4. Open that draftpart3 folder in File Explorer. Click the address bar, type cmd, and press Enter.
5. Check Python: py --version
6. Run: py -m unittest -v test_parser_kiran
7. Expected: Ran 12 tests and OK. Errors will show FAIL or ERROR; do not mark those as passed.
8. Generate and inspect ASTs: py demo_ast_kiran.py
9. To save your own results: py -m unittest -v test_parser_kiran > parser_test_results.txt 2>&1
10. To save your own demonstrations: py demo_ast_kiran.py > ast_demonstrations.txt
If py is unavailable but python works, substitute python for py. No third-party packages are required. If neither works, Python must be installed before running these commands.

## Full-input check
parse_expression is a component method: it may legitimately stop at a delimiter.
The test helper calls expect('EOF') after it, to validate complete standalone expressions.
For example, raw parse_expression('2 3') would consume only 2; the helper rejects the remaining 3.
This check is in the testing helper; the team's parser.py was not changed.
